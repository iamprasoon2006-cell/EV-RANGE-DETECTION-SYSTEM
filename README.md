# 🚗 EV Range Prediction System

## 📌 Project Overview
This project predicts the electric range of electric vehicles (EVs) using machine learning. It analyzes vehicle attributes such as manufacturer, model year, and vehicle type to estimate the driving range.

---

## 🎯 Objective
To build a machine learning model that predicts EV range and provides insights into EV adoption trends.

---

## 📊 Dataset
- Source: Kaggle
- Features:
  - Manufacturer (Make)
  - Model Year
  - Electric Vehicle Type
  - Electric Range (Target)

---

## 🧠 Machine Learning Models Used
- Linear Regression
- Random Forest Regressor (Final Model)
